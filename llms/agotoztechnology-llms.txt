## What AgotoZ sells

- Network as a service — ALLWAN global SD-WAN overlay; Linker / Linker Pro CPE intelligent access gateways
- Cloud networking — global integrated CDN, one-stop public cloud service, cloud connection between public clouds, global data centres and co-location
- Security as a service — SASE dynamic secure access, DDoS protection
- Value-added — Lingyin LinkTo global real-time transmission

Underlying technology the company names publicly: layer 2 to layer 7 SD-WAN, VxLAN, millisecond-scale
global dynamic routing, single- and bilateral TCP/UDP acceleration, efficient data compression,
high-performance caching.

## API surface — what an agent can and cannot do

**AgotoZ publishes no public API.** There is no developer portal, no API reference, no OpenAPI,
AsyncAPI, GraphQL SDL, Postman collection or JSON Schema, no SDK on any package registry, no CLI,
no webhook catalogue, no MCP server and no A2A agent card.

AgotoZ does operate a first-party API host on its own domain, and it is closed:

- `https://openapi.agotoz.com` — serves a valid wildcard `*.agotoz.com` TLS certificate. Over port
  80 an nginx instance answers every path, including `/openapi.json`, `/swagger.json`,
  `/v2/api-docs`, `/graphql`, `/mcp` and every `/.well-known/*` path, with an identical HTTP 403
  Forbidden. Over port 443 the TLS handshake completes but no HTTP response is returned to an
  anonymous caller. Nothing about its contract is public.
- `http://portal.agotoz.com` — a username / password / captcha login page ("agotz portal"). It is
  not linked from the public site, and its TLS certificate is expired and issued for a different
  hostname.

Access to the products is obtained through a sales conversation: every product and solution page
funnels to one trial-request form, and the published contacts are `xiaoshou@agotoz.com` (sales)
and `service@agotoz.com` (service).
